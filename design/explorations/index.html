Four directions for grant-ps.com

Each has a home page and one sample post (the opening section of PLAN.md, plus the Wrangler snippet so code blocks show). Pick one, or a mix such as "A's type with C's colour".

  1. A. Editorial

    Warm paper, Newsreader serif, centred reading column, small caps, a drop cap and fleurons. Quiet and bookish.

    Home · Post

  2. B. Engineering notebook

    Graph paper grid, IBM Plex Sans with JetBrains Mono, a margin column for metadata, terminal code blocks, follows the system dark mode.

    Home · Post

  3. C. Bold and experimental

    Cobalt, coral and lemon, huge Bricolage Grotesque, card layouts with hard shadows. The post includes a flare element (an animated time budget dial) to show what per-post flare can do.

    Home · Post

  4. D. Loud notebook (B with C)

    B's notebook structure (graph paper, sticky metadata column, mono labels, terminal code blocks, dark mode) with C's cobalt, coral and lemon, Bricolage Grotesque headlines, hard shadows and the time budget dial. Built to WCAG 2.2 AA: every text colour pair checked, coral used only as decoration, underlined links, a visible focus ring on every surface, keyboard-scrollable code, reduced-motion support, reflows to 320px.

    Home · Post

All three pass bin/guard against the sample markdown in sample/index.md. Links inside the explorations are relative so they work from this folder; the real site uses root paths.
